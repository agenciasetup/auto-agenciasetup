# 10 tarefas de social media pra passar pro Claude essa semana

Vale a pena usar o Claude? Depende do que você quer da sua semana. Se é ganhar tempo, cortar operação e focar em vender, comece por estas 10 tarefas. Cada uma vem com o pedido pronto para colar.

Feito pela Agência Setup (@agenciasetup).

## 1. Achar o assunto do dia

```
Procure as novidades dos últimos 3 dias sobre [o seu nicho] e me traga as 3 com mais chance de engajar, com a fonte de cada uma.
```

## 2. Montar o seu guia de estilo

```
Leia estes 15 posts meus e escreva o meu guia de estilo: como eu abro, como eu falo, o que eu repito e o que eu nunca diria.
```

## 3. Escrever o roteiro do carrossel

```
Com o meu guia de estilo, escreva um carrossel de 7 slides sobre [assunto]: capa, contexto, 4 pontos com uma prova cada e a chamada.
```

## 4. Escrever a legenda

```
Escreva a legenda deste post no meu estilo: a primeira linha é o gancho, depois 3 linhas curtas e uma pergunta no fim.
```

## 5. Criar 10 ganchos para testar

```
Me dê 10 ganchos diferentes para a capa deste post: curiosidade, número, polêmica, confissão e "se eu fosse você".
```

## 6. Fazer a arte por etapas

```
Faça a capa deste carrossel em HTML, em camadas: fundo, título, foto e efeitos, uma etapa de cada vez, me mostrando cada uma.
```

## 7. Transformar um post em Reels

```
Transforme este carrossel num roteiro de Reels de 40 segundos: gancho nos 3 primeiros segundos, frases curtas e a chamada no fim.
```

## 8. Responder comentários e direct

```
Aqui estão 20 comentários do meu último post. Sugira uma resposta curta para cada um, no meu tom, e marque os que viram venda.
```

## 9. Planejar a semana

```
Monte o meu calendário da semana: 5 posts, com o formato, o assunto e o objetivo de cada um (alcance, comentário ou venda).
```

## 10. Ler os números e dizer o que fazer

```
Aqui estão os números dos meus últimos 30 posts. Me diga o que funcionou, o que não funcionou e o que eu devo postar mais.
```

## O que fica com você

Escolher, ajustar uma palavra e aprovar. E vender.
